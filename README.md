# 🛍️ Premium E-Shop

A modern and responsive e-commerce web application built using React and Vite. The project provides a clean user interface for browsing products, managing a shopping cart, wishlist, and placing orders.

## 🚀 Features

- User-friendly interface
- Product listing
- Product details page
- Shopping cart
- Wishlist
- Checkout process
- Order confirmation page
- Responsive design

## 🛠️ Technologies Used

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3

# ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/premium-eshop.git
```

2. Navigate to the project

```bash
cd premium-eshop
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open your browser and visit:

```
http://localhost:5173
```
